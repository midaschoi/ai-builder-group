# A-07 승인 대기 `/admin/approvals`

| | |
|---|---|
| 우선순위 | **P0** |
| 접근 | **운영 관리자만.** 빌더 접근 시 **403** (FR-A07-05) |
| 셸 | ⭕ 적용 (A-00) |
| 핵심 임무 | 빌더가 쓴 것이 **검수 없이 고객 앞에 나가는 일을 막는 마지막 문** |

> 🔴 **승인 게이트는 타협 불가 항목이다** (PRD R8).
> 수주용 랜딩에서 근거 없는 수치나 미동의 고객사명이 그대로 공개되면 사업 리스크가 된다.
> "일단 빌더도 발행할 수 있게 하고 나중에 검수" 같은 절충안을 받지 않는다.

## 검토 화면 (FR-A07-02)

`[검토]` → 전체 폭 미리보기 + 하단 고정 액션 바

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ [← 승인 대기]   바이브 코딩 외주, 잘하는 곳과…    [Insight] 조쉬 · 08-14 제출    │
├──────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│    ┌────────────────────────────────────────────────────────────────────┐        │
│    │                                                                    │        │
│    │        공개 화면과 동일한 렌더 (P-05 템플릿 그대로)                │        │
│    │                                                                    │        │
│    │        제목 / 발행일 / 작성자 / 본문 / 목차 …                      │        │
│    │                                                                    │        │
│    └────────────────────────────────────────────────────────────────────┘        │
│                                                                                  │
├──────────────────────────────────────────────────────────────────────────────────┤
│  ⓘ 확인: 근거 없는 수치 · 미동의 고객사명 · 가격 소구                            │
│                                        [편집으로]   [반려]   [승인하고 발행]     │
└──────────────────────────────────────────────────────────────────────────────────┘
     ↑ 하단 고정 · 스크롤해도 사라지지 않는다
```

| 항목 | 스펙 |
|---|---|
| 렌더 | **공개 화면과 동일한 템플릿** (FR-A07-02). 관리자용 요약 뷰를 따로 만들지 않는다 |
| 접근 | **인증 필수** (PRD D3). ⛔ 공개 토큰 URL 금지 — 링크가 새면 미승인 콘텐츠가 노출된다 |
| 경로 | `/admin/approvals/[type]/[id]` — 미들웨어 게이트 안쪽 |
| 색인 | noindex (셸 전체 규칙) |
| 체크 안내 | 기획서 절대 규칙 3종을 하단 바에 상시 노출 — **매번 같은 것을 보게 한다** |
| `[편집으로]` | 관리자가 직접 고쳐서 발행할 때. 반려-수정-재제출 왕복을 줄인다 |

> ⚠ **선행 조건** — 공개 템플릿(P-05·P-03)이 아직 `/insight-detail`·`/work-detail` 한 장짜리 정적 페이지다.
> 관리자 단독 개발 구간에서는 **미리보기를 임시 렌더**로 만들고, 공개 웹 동적 라우트 전환 시 실제 템플릿으로 교체한다.
> 이 임시 렌더는 sanitize 된 `body_html` 을 그대로 그려 **정제 결과를 눈으로 확인하는 용도**도 겸한다.

## 승인 (FR-A07-03)

```
[승인하고 발행] → 확인 모달
┌────────────────────────────────────────┐
│  승인하고 발행할까요?                  │
│                                        │
│  「바이브 코딩 외주, 잘하는 곳과…」    │
│  발행하면 즉시 공개 사이트에           │
│  나타납니다. (반영까지 최대 60초)      │
│                                        │
│              [취소]  [승인하고 발행]   │
└────────────────────────────────────────┘
```

```
승인 → status = published
     → published_at = now()
     → 온디맨드 재검증 (목록 · 카테고리 · 상세 · sitemap)
     → 토스트: 발행했습니다 · 공개 반영까지 최대 60초
     → 승인 대기 목록으로 복귀 (다음 건을 바로 처리하게)
```

인수 조건: **60초 이내 공개** (FR-A07-03).

## 반려 (FR-A07-04) — **사유 없이 반려할 수 없다**

```
[반려] → 사유 입력 모달
┌────────────────────────────────────────────────────┐
│  반려 사유를 적어주세요                            │
│                                                    │
│  작성자에게 그대로 전달됩니다.                     │
│  무엇을 어떻게 고쳐야 하는지 적어주세요.           │
│                                                    │
│  ┌────────────────────────────────────────────┐    │
│  │ 근거 없는 수치("전환율 3배")가 있습니다.   │    │
│  │ 출처를 넣거나 문장을 빼주세요.             │    │
│  └────────────────────────────────────────────┘    │
│  24/500                                            │
│                                                    │
│  자주 쓰는 사유                                    │
│  [근거 없는 수치] [미동의 고객사명] [가격 소구]    │ ← 클릭하면 문장이 채워진다
│  [이미지 권리 미확인] [슬러그 규칙 위반]           │
│                                                    │
│                          [취소]  [반려하기]        │
└────────────────────────────────────────────────────┘
```

| 규칙 | 스펙 |
|---|---|
| 사유 | **필수.** 비어 있으면 `[반려하기]` 비활성 (FR-A07-04) |
| 최소 길이 | 10자. `안됨` 한 마디로 돌려보내면 작성자가 뭘 고칠지 모른다 |
| 저장 | `works.reject_reason` · `insights.reject_reason` (DR §7.2) |
| 작성자 노출 | 목록의 반려 탭 + **편집 화면 상단 배너** (A-03 §반려 배너) |
| 상태 전이 | `pending` → `rejected`. 작성자 편집 가능 상태로 풀린다 |
| 자주 쓰는 사유 | 기획서 절대 규칙에서 뽑은 5종. 클릭 시 본문에 문장을 채워 넣고 **수정 가능** |
| 재제출 | `rejected` → `draft` → `pending` (상태 머신 §7.3) |

> 자주 쓰는 사유 버튼은 **입력을 대체하지 않는다.** 문장을 채워 넣을 뿐이고, 그대로 보내도 되고 고쳐도 된다.
> 사유 코드만 저장하면 작성자가 받는 것은 "근거 없는 수치"라는 라벨 하나뿐이다. 어느 문장인지 모른다.

## 상태 전이 — 서버에서 막는 것 (DR-06)

```
초안(draft) ──제출──> 승인대기(pending) ──승인──> 발행(published) ──내림──> 보관(archived)
    ↑                        │                                              │
    └──────반려(rejected)────┘                                              │
    └──────────────────────────수정──────────────────────────────────────────┘
```

| 시도 | 결과 |
|---|---|
| 빌더가 `draft` → `published` 직행 | **403** (인수 조건) |
| 빌더가 `/admin/approvals` 접근 | **403** (FR-A07-05) |
| 빌더가 `pending` 상태 글 편집 | **거부** (DR-07 — 제출 후 잠금) |
| 관리자가 `published` → `archived` | ⭕ + **해당 URL 301 처리** (DR-08 — 404 아님) |
| 표에 없는 모든 전이 | **서버에서 거부** (DR-06) |

> 전이 판정은 **서버 액션 한 곳에** 모은다. 화면마다 흩어 놓으면 한 곳만 빠뜨려도 게이트가 뚫린다.

## 검수 항목

- [ ] 빌더 계정으로 `/admin/approvals` 접근 → **403** (FR-A07-05)
- [ ] Work 와 Insight 가 한 목록에 섞여 나오고 타입 배지로 구분되는가 (FR-A07-01)
- [ ] 미리보기 URL 을 로그아웃 상태로 열면 차단되는가 — **공개 토큰 URL 이 없는가** (PRD D3)
- [ ] 사유를 비운 채 반려 → 버튼이 비활성인가 (FR-A07-04)
- [ ] 반려 후 작성자 화면(목록·편집 배너)에 사유가 보이는가
- [ ] 승인 후 **60초 이내에 공개 페이지에 나타나는가** (FR-A07-03)
- [ ] 빌더가 API 로 직접 `published` 전이를 시도하면 403 인가 (DR-06)
- [ ] 사이드바 배지 수 = 목록 건수이고, 0건일 때 배지가 사라지는가
- [ ] `published` → `archived` 후 해당 URL 이 **301** 인가 (404 아님 · DR-08)
