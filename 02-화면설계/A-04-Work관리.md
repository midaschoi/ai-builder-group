## A-02 와 같은 것

상태 탭 · 검색 · 페이지네이션(12건) · 행 클릭 편집 · `[⋯]` 메뉴 · 빈 상태 · 빌더 필터링 규칙 ·
확인 모달 — **전부 A-02 스펙을 그대로 따른다.** 두 화면을 다르게 만들지 않는다.

> 목록 화면을 두 벌 따로 짜면 나중에 한쪽만 고치게 된다. **하나의 목록 컴포넌트를 컬럼 정의만 바꿔 쓴다.**

## A-02 와 다른 것

| 항목 | A-02 Insight | A-04 Work |
|---|---|---|
| 컬럼 | 제목 · 카테고리 · 작성자 · 상태 · 수정일 | 제목 · 카테고리 · **참여 빌더** · 상태 · 수정일 |
| 카테고리 | `type='insight'` (4종) | `type='work'` (Commerce · AI·AX · Platform · Finance …) |
| 썸네일 | 목록에 없음 | **목록에 썸네일 표시** (프로젝트는 이미지로 식별된다) |
| 작성자 | 단일 (`author_id`) | **다중** (`work_builders` 다대다) |

```

| 세부 | 스펙 |
|---|---|
| 썸네일 | 48×27 (16:9). 없으면 회색 플레이스홀더 — 빈 칸으로 두지 않는다 |
| 참여 빌더 | 첫 1명 + `+n`. 호버 시 전체 이름 툴팁 |
| 제목 없는 초안 | `(제목 없음)` 회색 표기. 초안은 제목이 비어 있을 수 있다 (A-03 §저장·검증) |
| 검색 대상 | 제목 · **참여 빌더 이름** |

## 화면 — 빌더

A-02 와 동일하게 **본인이 참여한 프로젝트만** 보인다.

> ⚠ Insight 는 `author_id` 단일이라 필터가 단순하지만, **Work 는 `work_builders` 다대다**다.
> "본인 것"의 판정 기준을 서버에서 명확히 잡는다:
>
> ```
> 본인 것 =  works.created_by = 나
>        OR  work_builders 에 (work_id, 나) 행이 있다
> ```
>
> 참여 빌더로만 연결된 프로젝트도 목록에 보여야 한다. 자기가 참여한 프로젝트를 못 보면 수정 요청을 못 한다.

| 차이 | 관리자 | 빌더 |
|---|---|---|
| 목록 범위 | 전체 | 본인 참여분만 |
| 삭제 | ⭕ | ❌ (403) |
| 발행 | ⭕ | ❌ — 제출만 |
| 보관 탭 | ⭕ | ❌ |

## 행 액션 `[⋯]`

A-02 와 동일: 편집 / 미리보기 / 보관(관리자) / 삭제(관리자).

### 삭제 시 추가 경고

```
┌──────────────────────────────────────────┐
│  이 프로젝트를 삭제할까요?               │
│                                          │
│  「iloom — 리빙 커머스 리뉴얼」          │
│                                          │
│  발행된 프로젝트입니다. 삭제하면         │
│  공개 페이지가 404 가 되고, 참여 빌더    │
│  3명의 프로필에서도 사라집니다.          │ ← Work 만의 파급
│  되돌릴 수 없습니다.                     │
│                                          │
│  대신 [보관하기] 를 권합니다 —           │
│  주소는 301 로 유지됩니다.               │
│                                          │
│              [취소]  [삭제]              │
└──────────────────────────────────────────┘
```

> Work 삭제는 Insight 보다 파급이 크다. **참여 빌더 연결(`work_builders`)이 함께 끊긴다.**
> 2차에 빌더 프로필(P-11)이 열리면 그 페이지의 "참여 프로젝트"에서도 빠진다.

## 빈 상태

오픈 시점에 Work 가 0건일 가능성이 높다 (기획서 Q4).

| 상황 | 문구 |
|---|---|
| 0건 (관리자) | `아직 등록된 프로젝트가 없습니다` + `[+ 새 프로젝트]` |
| 0건 (빌더) | `참여한 프로젝트가 없습니다` + `[+ 새 프로젝트]` |
| 필터 0건 | `조건에 맞는 프로젝트가 없습니다` + `[필터 초기화]` |
