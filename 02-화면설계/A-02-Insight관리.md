## 상태 탭

| 탭 | URL | 비고 |
|---|---|---|
| 전체 | `/admin/insight` | 기본. `archived` 제외 |
| 초안 | `?status=draft` | |
| 승인대기 | `?status=pending` | |
| 발행 | `?status=published` | |
| 반려 | `?status=rejected` | **0건이어도 탭을 숨기지 않는다** — 반려가 사라진 줄 알게 된다 |
| 보관 | `?status=archived` | 관리자만 |

- 탭 = **URL 반영.** 새로고침·뒤로가기·링크 공유가 동작해야 한다.
- 카운트는 탭 라벨에 함께 표기한다. `[승인대기 3]`
- 스타일: 알약형 · 선택 시 배경 `--ink` + 글자 `--paper`, 비선택 시 흰 바탕 + `--line` 테두리.

> 🟡 **레퍼런스의 상단 KPI 카드를 여기에 두지 않는 이유** — 레퍼런스는 상단에 큰 색 카드로
> `Total Listings 3,440` 같은 수치를 보여준다. 그런데 그 숫자들은 **우리 상태 탭이 이미 갖고 있는 값**이다.
> 카드로 한 번 더 보여주면 같은 숫자가 한 화면에 두 번 나온다.
>
> 탭은 숫자를 보여주는 동시에 **누르면 필터가 걸린다.** 카드는 보여주기만 한다.
> 정보량이 같다면 동작하는 쪽을 남긴다. (A-00 §4.4)

## 행 액션 `[관리 ▾]`

레퍼런스의 `[Manage ▾]` 형태. 점 세 개 아이콘 대신 **텍스트 버튼**을 쓴다 (A-00 §3.2).

| 액션 | 관리자 | 빌더 | 동작 |
|---|---|---|---|
| 편집 | ⭕ | ⭕(본인) | `/admin/insight/[id]` — 행 클릭과 동일 |
| 미리보기 | ⭕ | ⭕ | 인증 필요한 미리보기 라우트 (PRD D3 — 공개 토큰 URL ⛔) |
| 발행 취소 → 보관 | ⭕ | ❌ | `published` → `archived`. 확인 모달 + **301 안내** |
| 삭제 | ⭕ | ❌ | 확인 모달. 발행 상태면 "보관을 권합니다" 안내 동반 |

### 편집 진입 시 상태별 분기

| 대상 상태 | 빌더 | 관리자 |
|---|---|---|
| `draft` | 편집 ⭕ | 편집 ⭕ |
| `pending` | **읽기 전용** (DR-07 — 제출 후 잠금) | 편집 ⭕ |
| `published` | **읽기 전용** | 편집 ⭕ |
| `rejected` | 편집 ⭕ (반려 사유 배너 표시) | 편집 ⭕ |
| `archived` | 읽기 전용 | 편집 ⭕ |

## 검수 항목

- [ ] 빌더 계정으로 로그인 → **남의 글이 목록에 한 건도 없는가** (응답 본문까지 확인)
- [ ] 빌더가 남의 글 id 로 `/admin/insight/[id]` 직접 접근 → **403** (404 아님)
- [ ] 빌더의 `[관리 ▾]` 에 삭제가 없고, 서버 삭제 요청도 403 인가
