사이트 제작은 마무리 단계입니다. 다만 저희가 만들 수 없고 대표님만 발급받으실 수 있는 것 여섯 가지가 남아 있어, 한 번에 정리해 드립니다.

대상 AI 빌더 그룹 웹사이트 작성 2026-08-17

먼저 말씀드릴 것

아래 다섯 가지는 계정 소유권과 법적 책임이 대표님께 있어야 하는 항목입니다. 저희가 임의로 만들면 나중에 넘겨받으실 때 소유권이 꼬입니다.

전부 한 번에 주실 필요는 없습니다. 받는 대로 하나씩 반영하고, 반영이 끝나면 확인 결과를 보내드립니다. 다만 1번(문의 폼)은 없으면 오픈이 불가능합니다 — 문의가 실제로 접수되는지 확인할 방법이 없기 때문입니다.

6채널톡 플러그인 키 선택실시간 상담창이 뜨지 않음

항목별 안내

01 문의 폼(pluug) 주소와 설정 권한 오픈 불가

사이트의 모든 "프로젝트 문의" 버튼은 문의 폼으로 연결됩니다. 지금은 연결할 실제 주소를 받지 못해 화면만 준비된 상태입니다.

문의가 실제로 접수되고 알림이 가는지를 오픈 전에 한 번은 직접 넣어봐야 합니다. 이 확인이 계약상 완료 조건에도 들어가 있습니다.

필요한 것
① pluug 문의 폼의 공개 주소(URL)
② 제출 후 완료 페이지를 저희 사이트로 돌려보내는 설정 권한 또는 설정 대행 요청
왜 ②까지
제출이 끝나면 저희 사이트의 감사 페이지로 돌아와야 문의 완료가 통계에 잡힙니다. 돌아오지 않으면 몇 건이 접수됐는지 알 수 없습니다
대안
권한을 주기 어려우시면, 담당자 연락처만 주셔도 저희가 직접 협의하겠습니다
02 개인정보처리방침에 넣을 5개 항목 법적으로 필요

개인정보처리방침 페이지는 이미 만들어 두었습니다. 다만 사업자 정보는 저희가 알 수 없어 다섯 곳이 비어 있고, 화면에 눈에 띄게 표시되도록 해 두었습니다.

  • 시행일 — 방침을 적용하기 시작하는 날짜
  • 사업자 상호 — 등록된 정식 명칭
  • 개인정보 보호책임자 — 성명과 직위
  • 보호책임자 연락처 — 이메일과 전화번호
  • 문의 정보 보유 기간 — 문의 응대가 끝난 뒤 얼마나 보관할지 (예: 1년)
확인 부탁
본문에 플러그(pluug) · 채널톡 · Vercel 세 곳을 개인정보 처리 위탁사로 적어 두었습니다. 실제 계약과 맞는지 봐주세요
권장
공개 전 법무 검토를 한 번 받으시길 권합니다. 저희가 쓴 초안은 일반적인 형식이며 법률 자문이 아닙니다
03 구글 애널리틱스(GA4) 측정 ID 통계

방문자 수, 어느 화면에서 문의가 나왔는지 등을 보려면 필요합니다. 사이트 쪽 준비는 이미 끝나 있어 ID만 넣으면 바로 집계가 시작됩니다.

필요한 것
G- 로 시작하는 측정 ID 한 줄
어디서
analytics.google.com → 관리 → 데이터 스트림 → 웹 스트림 선택 → 우측 상단
중요
대표님 구글 계정으로 만들어 주세요. 저희 계정으로 만들면 나중에 소유권을 넘기는 절차가 따로 필요합니다
04 검색 등록용 확인 코드 (구글 · 네이버) 검색 노출

구글과 네이버에 "이 사이트가 내 것"임을 증명하면, 검색에 어떻게 노출되는지 확인하고 문제가 생겼을 때 알림을 받을 수 있습니다.

필요한 것
구글 서치콘솔 · 네이버 서치어드바이저에서 발급되는 HTML 태그 확인 코드 각 1개
순서
사이트를 등록하시면 확인 코드가 나옵니다 → 저희에게 전달 → 저희가 사이트에 심음 → 대표님이 "확인" 누르면 완료
참고
도메인(5번)이 정해진 뒤에 하시는 편이 낫습니다. 주소가 바뀌면 다시 해야 합니다
05 도메인 주소 임시 주소 사용 중

지금은 임시 주소(*.vercel.app)로 동작합니다. 기능에는 문제가 없지만 명함이나 홍보물에 넣을 주소는 아닙니다.

필요한 것
사용하실 도메인 주소. 아직 없으시면 후보만 주셔도 됩니다
이미 있으시면
도메인을 구입한 업체 이름과 관리자 페이지 접근 방법을 알려주세요. 연결 설정은 저희가 안내해 드립니다
바뀌는 것
도메인이 정해지면 사이트 주소, 검색 등록, 공유 미리보기가 모두 새 주소로 자동 전환됩니다. 추가 작업이 거의 없습니다
06 채널톡 플러그인 키 선택

방문자가 사이트에서 바로 채팅으로 문의할 수 있는 상담창입니다. 사이트 쪽 연결은 이미 끝나 있어 키만 넣으면 상담창이 나타납니다.

없어도 오픈에는 지장이 없습니다. 다만 개인정보처리방침 초안에 채널톡을 위탁사로 적어 두었으니, 쓰지 않기로 하시면 그 항목도 함께 빼야 합니다.

필요한 것
채널톡 플러그인 키
어디서
채널톡 → 채널 설정 → 보안 및 개발 → 플러그인 키
주의
키가 틀리면 아무 오류 없이 조용히 안 뜹니다. 넣은 뒤 저희가 실제로 열리는지 확인해 드립니다

보내주실 때

⚠ 비밀번호와 보안 키는 보내지 마세요

위 다섯 가지는 전부 공개되어도 안전한 값입니다 (측정 ID, 확인 코드, 폼 주소 등).

반면 계정 비밀번호, 로그인 정보, API 비밀 키는 메신저나 이메일로 주고받으면 안 됩니다. 그런 것이 필요한 경우에는 저희가 초대 링크를 보내드리고 대표님이 직접 설정하시는 방식으로 진행합니다.

형식
따로 정해진 양식은 없습니다. 번호와 값만 적어 회신해 주시면 됩니다
순서
전부 모으실 필요 없이 받는 대로 하나씩 보내주셔도 됩니다
회신 후
반영하고 실제로 동작하는지 확인한 결과를 함께 보내드립니다

정리

  1. 문의 폼(pluug) 주소 + 완료 페이지 설정 — 가장 급합니다
  2. 개인정보처리방침 5개 항목 (시행일 · 상호 · 보호책임자 · 연락처 · 보유 기간)
  3. GA4 측정 ID (G- 로 시작)
  4. 검색 확인 코드 구글 · 네이버
  5. 도메인 주소 또는 후보
  6. 채널톡 플러그인 키 — 상담창을 쓰실 경우에만

궁금한 점이나 발급이 막히는 항목이 있으면 말씀해 주세요. 화면을 같이 보면서 도와드리겠습니다.
